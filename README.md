# Synthetic Healthcare Interoperability Pipeline

An educational Python project demonstrating synthetic clinical data
generation, normalization, FHIR mapping, validation, storage, and retrieval.

## Planned MVP

- Generate entirely fictional patients and observations.
- Normalize records into common internal models.
- Map records to FHIR R4 4.0.1 Patient and Observation resources.
- Validate records and produce auditable reports.
- Store accepted records in SQLite.
- Expose read-only retrieval endpoints through FastAPI.

## Project constraints

- Python-first implementation.
- Google Colab for development.
- GitHub for source control.
- No additional monetary cost.
- No paid APIs, paid hosting, or billable service dependencies.
- No real patient data.

## Data and clinical-use notice

All patient records, identifiers, and clinical observations must be
entirely synthetic. Do not upload real medical records or identifiers.

This is an educational portfolio project, not a production clinical
system, a diagnostic tool, or a claim of HIPAA compliance.
